脱出速度計算機

孤立した天体の重力場から脱出するための最小初速度を計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

脱出速度 v_esc

—

値を入力し「計算する」を押してください。

公式

v_esc = √(2GM/r)

適用条件

M,r>0。天体外部の球対称なニュートン重力場を仮定します。r は高度ではなく天体中心からの距離です。大気、自転、他の天体、継続的な推力は考慮しません。計算結果が光速以上になる入力は受け付けません。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
