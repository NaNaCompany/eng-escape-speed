# 신규 공학 계산 도구 50개 · E051~E100 배포 기록

기록일: 2026-10-25. 탈출속도·공전주기·호만 전이·상대론·재료·열유체·전자·광학·음향·화학·측정 계산기 50개를 각각 독립 리포와 GitHub Pages로 배포했습니다. 기존 E001~E050과 다른 계산 모델입니다. 각 앱은 `ko·en·es·zh·ja·de` 6개 언어를 지원하므로 신규 공개 페이지는 300개입니다.

## 검증

- 독립 고정밀 기준값, 입력·출력 단위, 정의역과 특수 경우를 포함한 Node 명명 테스트 1,000개 통과.
- 300개 페이지를 320px와 1280px Chromium viewport에서 실행한 600건 통과. 계산·오입력·언어 오류·가로 넘침·More Apps·언어 링크를 검사했습니다. 실물 휴대전화와 모바일 Safari는 이 검증에 포함하지 않습니다.
- GitHub CI 50개 성공. Pages 배포 커밋과 푸시 커밋 50개가 일치합니다.
- 공개 페이지 300개의 언어·제목·canonical·hreflang·게시자 코드 확인. 6개 언어 설정·대표 이미지와 공통 계산·단위·스타일·사이트맵 파일을 로컬 검증본과 대조했습니다.
- 기존 50개 소스·Git 이력과 당시 검증 기록을 보존했습니다. 이전 50개를 합친 공개 앱은 100개, 언어 페이지는 600개입니다.

## 구조와 저작권

`tool.json`, `localization/*.json`, `src/template.html`, `scripts/build-locales.py`가 재생성 원본입니다. 실행 시 수치는 브라우저에서 계산하며 번역 API를 호출하지 않습니다. ko 루트와 5개 언어 하위 경로에 개별 SEO 메타데이터, `zh-CN`을 포함한 hreflang, JSON-LD와 직접 제작한 1200×630 대표 이미지를 제공합니다.

코드·설명·아이콘·대표 이미지를 직접 작성했습니다. 외부 교재 본문·도판·사진·계산기 코드를 복제하지 않았고 외부 폰트 파일을 재배포하지 않습니다. 참고한 공식·물리상수의 원문 링크와 공급자 스크립트의 별도 권리 구분은 각 리포의 `SOURCES.md`에 기록했습니다. 자체 제작 코드는 MIT 라이선스입니다. 외부 원어민 감수는 포함하지 않습니다.

GTM·GA4·AdSense·Cloudflare 분석 코드와 우측 하단 작은 회색 `More Apps` 링크(`https://nanalab.kr/apps/`)를 적용했습니다. 태그 코드 존재 확인과 분석 서비스의 실제 수집 성공은 구분합니다.

공개 탈출속도 계산기를 390px·1280px에서 추가 실행해 지구 예제 약 11.186 km/s와 정상 상태 메시지를 확인했습니다. 공개 사이트의 자동 광고는 화면 일부를 가릴 수 있습니다. 광고 닫기 클릭은 자동 승인 검토가 광고 오클릭 위험으로 차단하여 실행하지 않았으며 광고 설정은 변경하지 않았습니다. 이 추가 확인은 로컬 600건 검사와 구분해 `public-ui-review.json`에 기록했습니다.

## 사이트맵과 본사이트 반영

각 앱의 `sitemap.xml`은 6개 URL과 7개 언어 대체 링크를 갖는 leaf `urlset`입니다. `engineering-tools-locale-sitemap.xml`에는 기존 300개와 신규 300개, 총 600개 URL을 중복 없이 합쳤습니다. 최초 `published_at`에는 GitHub 저장소 생성 시각을 사용하며 유지보수 시각으로 덮어쓰지 않습니다.

이 문서 생성 시점의 본사이트 반영은 대기 상태입니다. `UpdateQue.md` 원문과 기존 작업 항목을 보존하며 신규 50개 카드와 50개 개별 사이트맵 연결 요청을 추가했습니다. 본사이트 루트 `/sitemap.xml`은 sitemapindex이므로 개별 앱 지도 100개를 연결하면 언어 페이지 600개를 발견할 수 있습니다. 이미 연결된 개별 지도와 병합 XML을 함께 등록해 같은 URL을 중복 제출하지 않습니다.
